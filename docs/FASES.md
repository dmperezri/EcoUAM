# Desarrollo por fases

1. Inicialización: estructura, dependencias, navegación y PWA base.
2. Identidad visual y página de inicio: revisar la propuesta base con el usuario.
3. Mapa real: solicitar el plano autorizado; no inventar coordenadas.
4. Zonas verdes: fichas con ubicación y fuentes verificadas.
5. Meteorología: validar acceso, actualización, atribución y estado sin datos.
6. Biodiversidad y educación: identificar especies con evidencia.
7. Galería y cuestionario: fotografías con permisos y preguntas revisadas.
8. Offline e instalación: ampliar estrategia PWA y pruebas de actualización.
9. Pruebas en teléfono y laptop: accesibilidad, rendimiento y navegadores.
10. GitHub y Vercel: publicación pública. El repositorio se conectó anticipadamente por solicitud del usuario.

Solo la fase 1 está implementada. Cada módulo pendiente usa la misma pantalla de estado. No hay contenido provisional presentado como real.
